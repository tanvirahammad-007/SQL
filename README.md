# SQL Practice

A collection of SQL practice exercises and solutions based on the [SQLBolt](https://sqlbolt.com/) lessons.

The purpose of this repository is to build a strong foundation in SQL through consistent practice, while keeping the queries organized and easy to review.

## Topics Covered

- SELECT queries
- Filtering with WHERE
- Comparison and logical operators
- BETWEEN, IN, LIKE, and other constraints
- ORDER BY and LIMIT
- DISTINCT
- Aggregate functions
- GROUP BY and HAVING
- JOINs
- OUTER JOINs
- NULL values
- Expressions and calculated columns
- Query execution order
- INSERT
- UPDATE
- DELETE
- CREATE TABLE
- ALTER TABLE
- DROP TABLE
